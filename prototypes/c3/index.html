Alternative A — Printed controls

A manual control system: item labels, custody cards, manifest checking, repair tags, and reconciliation. Nothing is automatically enforced.

Use the existing printable issue and return forms as the actual physical prototype. The checklist below is a procedure rehearsal, not an inventory database.

Why it matters

This solution changes the physical process with minimal technology.

Strength: usable offline; no phone required.

Risk: a paper entry may not reflect actual physical handover. Double issue and return disputes still depend on operator diligence.

Evidence needed: staff effort, accuracy of completed paper cards, audit results, and cost of operating this method.

Explicit limitation: checking boxes here does not demonstrate that a human performed these actions in Alaknanda.
