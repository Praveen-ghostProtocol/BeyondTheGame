## Evidence gaps that block outcome claims

1. Actual physical item census and condition counts (the 80:20 ratio is unmeasured).
2. Independent triad-accountability audit.
3. Representative register volume and matched task timings (5 minutes is recalled).
4. Permission for observation/live system changes; stakeholder/guard validation.
5. Actual financial office rules and repair/purchase case timestamps.

If unavailable during Phase C, run **explicitly staged** concept tests and label them as such. Never silently convert hypothetical examples to field results.
