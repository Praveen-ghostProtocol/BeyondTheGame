# C2 → C3: Readiness and pending decisions

## What is ready now
- 12 standardized matched scenarios that together exercise the highest-priority C1/B4 cases, while all 32 B4 cases remain in the reference acceptance suite.
- Explicit data capture templates for participant trial performance, independent physical audits and ownership cost.
- Strict accountability, design-only assessment, eight non-compensatory evaluation gates and proposed (not approved) multi-criterion weights.
- Reproducible evaluator and tests that refuse to conflate no data with zero performance.

## What is NOT ready
- No completed physical proof-of-concept trials, participant measurements, verified accountability baseline, reliable procurement cost comparison or selected winning candidate.
- C1 HTML concept screens are visuals, not end-to-end authenticated deployed transactions.

## C3 pilot prerequisites for owner approval
1. Consent-based test access (prefer staging with personal data removed, followed by limited live pilot as authorized).
2. Selection of item types, kit components, participants and an independent checker. Guard's role should not expand without permission.
3. Maximum acceptable user/captain issue overhead; use both timed experience and accountability.
4. Proposed criterion weights and any new gates; user signs off before a final reconstruction choice.

**Provisional roadmap:** staged trials → analyze evidence/gates → one evidence-based refinement → retest → recommendation for user approval → selected Phase D reconstruction. Until then the project should not claim one concept is the winner.
