# A3 — Consolidated baseline information request

**Status:** Historical questionnaire; A3 Q1–Q9 were answered in the subsequent interview. Q10 and Q11 remain open. Canonical analysis: [A3 baseline study](a3-baseline-study.md). Responses can say *unknown*, *estimated*, or *documented*; never silently treat estimates as measurements.

1. **Existing register access:** Can you supply anonymous totals for 7 consecutive days (date, number of issue entries, number of returns, rough peak hours)? If not, is a small 1–2 day observation possible? No student names/signatures/IDs.
2. **Time components:** In the reported 5-minute collection journey, approximately how much is room-to-guard walking, guard/register interaction, guard-to-sports-room walking and actual pickup? Which components are assumptions rather than stopwatch measurements?
3. **Equipment audit feasibility:** Could you provide a non-identifying photograph or quick categorized condition count for a representative set (e.g., 10–20 items across cricket, badminton, football/volleyball and TT)? If no count is accessible, should we create a small consented physical audit protocol for future execution?
4. **Recorded versus physical status:** Are there known concrete instances of a register entry listing an item as returned although the item was missing or damaged? Describe only events you actually remember; dates and counts can remain unknown.
5. **Recent damage cases:** Aside from the one reported expensive cricket bat incident, do you recall any separately identifiable real damage/repair case with an approximate item, time, response and final outcome? Otherwise answer 'no separate documented cases'.
6. **Repair timing:** For a typical recent repair, approximately how long did it take from discovery to decision, approval/payment, shop work and restoration? Mark each interval as recalled or supported by records.
7. **Purchase chronology:** Can you give details of one below-₹10,000 and one ≥₹10,000 actual purchase: amount or range, quotes, office lead time, shop collection time and invoice availability (redacted)? If neither example exists, say so.
8. **Tournament exception:** Roughly how often do captains use verbal secretary permission to bypass the register rather than sign out normally? Unknown is acceptable; do not invent a percentage.
9. **Primary success measure:** Would you approve 'valid requests fulfilled with usable equipment within a predefined service window' as the primary metric, or prefer 'verified asset accountability' / 'equipment downtime'? Which reflects the project need best?
10. **Practical measurement permissions:** Can a small number of consenting students/guards complete timed simulated check-outs, returns and inspections later, and can you photograph non-identifying equipment/storage? Identify any limits imposed by hostel management.
11. **Study boundary:** Should first measurements cover ordinary borrowing only, or also tournament kit handovers and repair cases? Recommend a representative baseline with separately labelled subgroups.

**Collection rules:** No personally identifiable student register data in public repo. Log sample sizes and data provenance. Simulated workflows are valid for method testing but are *not* represented as actual operational performance.
