# B3 scenario exports — entirely hypothetical

These CSV files are generated by `python models/b3/scenario_model.py`, using the *Python standard library*. They **do not contain field transactions, audit results or measured accountability rates**.

| CSV | Purpose |
| --- | --- |
| `hypothetical-record-completeness.csv` | Shows sensitivity of all-required-records capture probability to transfers and recording compliance, under independently assumed events. NOT correctness. |
| `hypothetical-workload-tradeoff.csv` | Converts estimated sport-use occasions and assumed loan rates/extra seconds into potential weekly administrative minutes. NOT measured loans. |
| `hypothetical-stock-reconciliation.csv` | Proves the status-inventory arithmetic using 50 fictitious assets. |
| `hypothetical-normalized-accountability.csv` | Illustrates denominators using fabricated category-level sample counts; NOT field accuracy. |

The workbook at `data/baseline/b3-transformer-model.xlsx` is also scenario-oriented. Current real accountability remains unmeasured.
